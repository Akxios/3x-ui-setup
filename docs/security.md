# Безопасность установки

[README](../README.md) · [Установка](installation.md) · [Настройки `.env`](configuration.md) · [Эксплуатация](operations.md)

Установщик выполняется от root и меняет nginx, UFW, Fail2Ban, сертификаты и системные службы. Проверяйте код и `.env` перед запуском на сервере с существующими данными.

## Код и конфигурация

`.env` читается как данные: поддерживаются только известные ключи, Bash-код и подстановка команд не исполняются. Значения домена, путей и других чувствительных настроек проверяются до применения. Файл получает права `600`; учётные данные 3x-ui и карточка доступа тоже хранятся в закрытых файлах. Не отправляйте их вместе с логами.

Обычная однострочная установка загружает `bootstrap.sh` из `main` и без `REPO_COMMIT` обновляет текущую ветку. Это удобно, но код может измениться между запусками. Для воспроизводимой установки скачайте `bootstrap.sh` по SHA проверенного коммита и передайте тот же SHA в `REPO_COMMIT`. Тогда checkout переключается на этот коммит до запуска кода проекта.

Официальный `install.sh` 3x-ui скачивается по HTTPS и перед запуском сверяется с `THREE_X_UI_INSTALL_SHA256`. Версия `v3.8.5` и сумма закреплены по умолчанию. При смене версии нужны совместимый API и ожидаемая сумма именно нового файла из доверенного источника. Проверка одного файла не ограничивает другие загрузки, которые выполняет сторонний installer от root.

## Сеть и доступ

UFW по умолчанию запрещает входящие подключения, разрешает исходящие и сохраняет обнаруженный SSH-порт. Если SSH-порт определить нельзя, установка останавливается до включения UFW. Существующие правила не сбрасываются по умолчанию. Скрипт не меняет порт SSH, ключи, парольную аутентификацию и root-login.

Панель и подписки привязываются к `127.0.0.1` и доступны извне через HTTPS nginx на `443/tcp`. Внутренний TLS 3x-ui отключён, поэтому nginx использует локальный HTTP и не требует `proxy_ssl_verify off`. Домен, внешний firewall провайдера и Xray inbound остаются под управлением администратора.

По умолчанию для новой панели логин, пароль и пути панели/подписок генерируются случайно. На существующей панели сохраняются действующие пути, чтобы не разорвать клиентские ссылки. Проверка установки подтверждает вход в панель и маршрут до сервиса подписок; без клиента она не подтверждает содержимое персональной подписки.

## Существующий сервер

Проект заменяет только nginx-сайт с маркером `# Managed by 3x-ui-setup` и собственные файлы Fail2Ban. Перед reload выполняется `nginx -t`, а при ошибке конфиг откатывается. Чужой сайт и пользовательский `jail.local` сохраняются. По умолчанию удаление также оставляет web-root, сертификаты, данные панели и пакеты; дополнительные действия требуют отдельных флагов в `.env`.

Сайт и панель используют один HTTPS-домен. Если вы добавите на сайт стороннее приложение или пользовательский контент, его уязвимости могут затронуть панель через общий origin. Для такого сайта выделите панели отдельный домен.
